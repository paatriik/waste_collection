# waste_collection — Danderyd source for `hacs_waste_collection_schedule`

Working repository for adding **Danderyds kommun (Stockholm, Sweden)** to
[mampfes/hacs_waste_collection_schedule](https://github.com/mampfes/hacs_waste_collection_schedule).

This is a *staging* repo. The upstream project only accepts changes via a pull request
from a fork, so the files here mirror upstream's directory layout exactly and can be
copied into a fork with no path rewriting.

## Layout

| Path | Purpose |
|---|---|
| `custom_components/waste_collection_schedule/waste_collection_schedule/source/danderyd_se.py` | The source module (the actual deliverable) |
| `doc/source/danderyd_se.md` | User-facing doc page — upstream requires this to be written by hand |
| `research/` | Investigation notes and the endpoint-capture script. **Not** part of the upstream PR |

## Upstream contribution rules that constrain this work

Taken from upstream `CLAUDE.md` and `doc/contributing_source.md`:

- A PR must contain **only** the two files above. `README.md`, `info.md`, `sources.json`,
  `source_metadata.json` and the `translations/*.json` files are generated by CI post-merge;
  including them fails review.
- No hardcoded schedules. The source must fetch from a live endpoint on every `fetch()`.
- No login-required endpoints. Only publicly reachable URLs.
- `ICON_MAP` values must be members of the `Icons` enum, not raw `mdi:` strings.
- `PARAM_TRANSLATIONS` / `PARAM_DESCRIPTIONS` / `HOW_TO_GET_ARGUMENTS_DESCRIPTION` may only
  use the keys `en`, `de`, `it`, `fr`. Swedish (`sv`) is **not** in the allowlist and will
  fail CI.
- Errors must raise the typed exceptions from `waste_collection_schedule.exceptions`
  (`SourceArgumentNotFound`, `SourceArgumentNotFoundWithSuggestions`, …), never a bare
  `Exception`, and never `return []`.
- `COUNTRY` must be `"se"`.
- `TEST_CASES` must not contain a contributor's home address. Use civic addresses.
